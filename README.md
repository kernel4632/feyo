# FEYO

**F**low、**E**ase、**Y**ield、**O**rientation。

FEYO 是一个面向高专注、高体验感 Web 应用的 UI 设计系统与组件库。
参考 DankMaterialShell 的设计结构与组件行为，最终打包为通用 Web Components。

## 技术栈

Vue 3 · JavaScript · Vite · SCSS · Hugeicons · pnpm

## 开始

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
pnpm preview
```

## 目录

```
src/
  styles/          设计 token 与全局样式
  components/      组件
  App.vue          开发预览页
  main.js          开发入口
```

协作约定见 [AGENTS.md](./AGENTS.md)。
